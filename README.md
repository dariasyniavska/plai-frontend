# Plai Frontend

Простий фронтенд для сайту «Плай» (гірські маршрути Карпат). Працює з бекендом на Django REST Framework: показує маршрути, 
дозволяє зареєструватися, увійти, переглянути профіль і вийти. Бекенд знаходиться в окремому репозиторії `plai`.

## Функціонал

| Сторінка | Файл | Доступ |
|---|---|---|
| Список маршрутів | `index.html` | усі |
| Реєстрація | `register.html` | лише неавторизовані |
| Вхід | `login.html` | лише неавторизовані |
| Профіль | `profile.html` | лише авторизовані |

Поведінка:

- Неавторизований користувач, який відкриває профіль, перенаправляється на 
сторінку входу (`login.html?next=profile.html`). Після входу його повертає на сторінку, з якої перенаправило.
- Авторизований користувач не може відкрити сторінки входу та реєстрації: його перенаправляє на `index.html`.
- Неавторизований користувач у меню бачить «Увійти» та «Реєстрація». Авторизований бачить своє імʼя та кнопку «Вийти».
- При виході `access` і `refresh` токени видаляються з браузера.
- Коли `access` токен закінчується (бекенд відповідає `401`), фронтенд автоматично отримує новий 
за допомогою `refresh` токена і повторює запит. Якщо оновити не вдалося, користувача перенаправляє на вхід.
- Адміністратор додатково бачить на профілі форму додавання гірського масиву.
- Помилки валідації з бекенду показуються біля форм (для кожного поля).

## Структура

- `auth.js`: спільна логіка (збереження токенів, запити з заголовком `Authorization: Bearer ...`, 
оновлення токена, перенаправлення, меню).
- `style.css`: стилі.
- `index.html`, `login.html`, `register.html`, `profile.html`: сторінки.

## Як запустити проєкт

1. Запустіть бекенд (репозиторій `plai`), інструкція в його README. Бекенд має працювати 
за адресою `http://127.0.0.1:8000`:

   ```bash
   python manage.py runserver
   ```

2. Створіть адміністратора на бекенді (потрібен, щоб побачити форму для адміністратора):

   ```bash
   python manage.py createsuperuser
   ```

3. Відкрийте `index.html` у PyCharm і натисніть значок браузера у правому верхньому куті редактора. 
Фронтенд запуститься на вбудованому сервері PyCharm за адресою `http://localhost:63342/`.

Адреси та порти:

| Частина | Адреса |
|---|---|
| Бекенд (Django) | `http://127.0.0.1:8000` |
| Фронтенд (сервер PyCharm) | `http://localhost:63342` |

Адреса бекенду задана в константі `API_URL` на початку `auth.js`.

Не відкривайте HTML-файли напряму з диска (`file://...`): браузер надсилатиме запити з origin `null`, 
і сервер їх може відхиляти.
