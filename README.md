# Plai Frontend

Простий фронтенд-додаток для демонстрації зв'язку з бекендом через API та перевірки CORS.

## Як запустити проєкт

1. Переконайтеся, що у вас запущений бекенд-сервер Django на порту `8000`:
   ```bash
   python manage.py runserver
2. Відкрийте файл index.html у браузері (або за допомогою розширення Live Server у VS Code / PyCharm).
3. Сторінка автоматично надішле запит на http://127.0.0.1:8000/api/v1/routes/ та виведе список маршрутів.
